# AWS Cloud Labs

Hands-on labs from the AWS re/Start program. Each lab has the steps I followed, screenshots, and what I learned.

## Skills practiced
- AWS CLI and IAM
- EC2, Elastic Load Balancing, and Auto Scaling
- VPC networking
- S3 storage
- Lambda (serverless)
- RDS databases
- CloudTrail logging
- Linux command line and SSH

## Labs

| # | Lab | What I did |
|---|-----|------------|
| 01 | [Install and Configure the AWS CLI](./01-install-configure-aws-cli) | Installed the CLI on a Red Hat EC2 instance, configured it with an access key, and pulled an IAM policy from the terminal |
| 02 | [Configuring an Amazon VPC](./02-configuring-amazon-vpc) | Built a VPC with subnets and routing |
| 03 | [Scale and Load Balance Your Architecture](./03-scale-and-load-balance) | Set up a load balancer and auto scaling for EC2 instances |
| 04 | [S3 Challenge](./04-s3-challenge) | Completed an S3 challenge without step by step instructions |
| 05 | [Lambda Challenge](./05-lambda-challenge) | Built a serverless function with Lambda |
| 06 | [Working with CloudTrail](./06-cloudtrail) | Tracked account activity using CloudTrail logs |
| 07 | [RDS Challenge Lab](./07-rds-challenge-lab) | Launched an RDS database, connected over SSH, and ran SQL queries |
